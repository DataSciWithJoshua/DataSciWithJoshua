### AI JPEG Interrogation and Structured Extraction  
Case study — proprietary proof of value

Designed a system to extract structured information from engineering prints and images using generative AI techniques. The work emphasized reliability, repeatability, and cost-performance tradeoffs, with a focus on systematic processing rather than one-off inference.

### Improving ASR Quality with VAD and Whisper  
Case study — applied machine learning and evaluation

Explored methods to reduce hallucinations in automatic speech recognition systems by incorporating voice activity detection. The work focused on isolating speech regions, suppressing noise, and evaluating transcription behavior across challenging audio conditions.

Representative implementations are available upon request.

---

### RAG System for Safety Standards (Azure Databricks)  
Case study — enterprise generative AI

Developed a retrieval-augmented generation system to answer domain-specific questions over internal safety standards. The system integrated document ingestion, embedding, retrieval, and LLM-based response generation, with a strong emphasis on grounding responses to reduce hallucinations in a regulated engineering context.

The implementation is not public due to proprietary data and systems.
